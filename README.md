# Anup Kumar — Portfolio

A modern, responsive personal portfolio website.

## 🔗 Live
**[01-anupkr.github.io](https://01-anupkr.github.io)**

## ✨ Features
- Dark/Light theme toggle with persistence
- Interactive particle background (Canvas API)
- Smooth scroll animations & typewriter effect
- Fully responsive design
- Skills tabs (Frontend, Backend, AI/ML/GenAI, Tools)
- Real GitHub project showcase
- Contact form with validation

## 🛠 Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)
- Lucide Icons
- Canvas API for particles
